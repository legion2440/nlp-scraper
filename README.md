# NLP Scraper

NLP-enriched news intelligence pipeline for the 01 Edu AI track.

The project will:

- scrape at least 300 recent news articles;
- detect organizations with spaCy NER;
- classify article topics with a trained BBC News classifier;
- analyze sentiment;
- rank articles by environmental-scandal similarity;
- export enriched results to `results/enhanced_news.csv`.

Implementation follows the project subject and audit requirements.
